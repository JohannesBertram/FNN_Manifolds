Neural Manifold Explorer

Interactive explorer for the paper "Manifolds and Modules: How Function Develops in a Neural Foundation Model" (NeurIPS 2025, Data on the Brain and Mind workshop). Each link opens a fully self-contained interactive 3-D manifold viewer — no installation required.
